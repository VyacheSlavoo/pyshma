# Передача работы в новую сессию

Задача: готовый к публикации сайт бетонного завода для точки https://yandex.ru/maps/-/CXe6qB3-.
Требования: `docs/TZ-master-prompt.md` (ТЗ пользователя, копия). Структура по образцу https://ulyanovka-beton.ru/.
Фото и прайс берём из карточки на Яндекс Картах. Заявки уходят на почту Ульяновки через Бегет.
Режим работы везде 24/7, без вариантов.

## Что мешало в первой сессии

Сеть окружения закрыта: прокси отвечал 403 на `yandex.ru`, `ulyanovka-beton.ru`, `api.beget.com`,
`avatars.mds.yandex.net`. Пользователь добавил хосты в Allowed domains, но это читается при старте контейнера.
Данные точки (адрес, телефон, цены, фото) не получены. Ничего из этого не выдумывалось: `content/*.json` пусты.

## Первый шаг новой сессии

```
for u in https://yandex.ru/maps/-/CXe6qB3- https://ulyanovka-beton.ru/ https://avatars.mds.yandex.net/; do
  curl -sS -m 25 -o /dev/null -w "$u %{http_code}\n" "$u"; done
```

Если 403: сообщить пользователю хост и остановиться на этом шаге. Нужны ещё `yastatic.net` и, для проверки почты, ничего
(SMTP Бегета по порту 465 через прокси не пройдёт, его проверять только на хостинге).
Если Яндекс отдаёт капчу или пустую страницу без JS: попросить пользователя вставить в чат адрес, телефон, товары и цены,
фото приложить файлами.

## Карта URL (решено)

`/`, `/price/`, `/catalog/{категория}/`, `/catalog/tovarnyy-beton/m300/` (только марки из `site.mark_pages`),
`/catalog/arenda-abn/`, `/dostavka/`, `/{город}/` для 1–2 приоритетных городов, `/dostavka/{посёлок}/` для мелких,
`/contacts/`, `/about/`, `/privacy/`, `/soglasie/`. Категории создаются только если есть строки в `prices.json`.
Редиректы (`.htaccess`): http→https, www→основной хост, `/index.html`→`/`, `/catalog/`→`/price/`.

## Вопросы к пользователю (не угадывать)

- Домен нового сайта.
- Адрес почты Ульяновки, на которую отправлять заявки, и ящик Бегета, с которого идёт отправка (логин и пароль только в серверный конфиг).
- Рабочие ссылки мессенджеров.
- Входит ли доставка в цену бетона (`delivery.price_includes_delivery`), условия простоя, вместимость миксера.
- 1–2 приоритетных города спроса, у которых будут свои страницы, и расстояния/цены доставки до них.
- Какие марки получают отдельные страницы (по спросу).
- Есть ли аренда АБН и её параметры.
