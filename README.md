# Сайт бетонного завода «Бетон Микс», Верхняя Пышма

Статический сайт (HTML без рантайм-фреймворков) для завода на ул. Обогатителей, 8. Цены, фото и отзывы взяты из карточки
на Яндекс Картах, структура разделов повторяет ulyanovka-beton.ru и ekaterinburgbeton.ru. Сайт собирается в папку `dist/`:
её содержимое целиком загружается на хостинг.

Адрес по умолчанию: `https://verhnyaya-pyshma.ekaterinburgbeton.ru` (поддомен основного сайта). Меняется одной строкой
`domain` в `content/site.json`, потом `npm run build`.

## Что внутри

26 страниц: главная, прайс-лист, 11 разделов продукции (7 видов бетона, растворы, ЦПС, арматура, аренда АБН), 4 страницы
марок (М200, М250, М300, М350), доставка, геостраница Екатеринбурга, фото, о заводе, контакты, политика и согласие,
«спасибо» и 404. Режим везде 24/7, НДС не упоминается, год основания и лаборатория не заявлены: в карточке этого нет.

## Команды

```
npm install
npm run import        # обновить прайс, отзывы и список фото из карточки Яндекс Карт (нужен доступ к yandex.ru)
npm run build         # собрать dist/ (падает, пока обязательные поля в content/site.json пусты)
npm run check         # приёмка по ТЗ: проходы 1–4 (разметка, SEO, факты, композиция)
npm run check -- --layout   # + проход 5: Chromium на 320/375/430/1280 px и «холодный взгляд» на первый экран
npm run build:fixture # сборка на вымышленных данных tests/fixture (noindex), для проверки движка
```

Цены обновляются раз в месяц: `npm run import && npm run build`, затем загрузить `dist/`. Дата «Актуально на …» ставится
автоматически (1-е число месяца сборки).

## Выкладка на Бегет

1. В панели Бегета добавьте сайт для поддомена `verhnyaya-pyshma.ekaterinburgbeton.ru`, в DNS домена поддомен
   направьте на хостинг (A-запись), включите бесплатный SSL (Let's Encrypt).
2. Загрузите **содержимое** `dist/` в корень сайта (`public_html`), включая скрытый `.htaccess`.
3. Создайте почтовый ящик `zayavki@ekaterinburgbeton.ru` (Почта → Создать ящик). Для отправки с домена в DNS должны быть
   SPF и DKIM Бегета, иначе письма уйдут в спам.
4. Скопируйте `send.config.example.php` в `send.config.php`, лучше на уровень выше `public_html`. Впишите пароль ящика
   в `smtp_pass`. Получатель заявок `to` по умолчанию `info@ulyanovka-beton.ru` (как вы просили), можно несколько адресов
   через запятую. Файл с паролем в репозиторий не попадает (`.gitignore`).
5. Отправьте тестовую заявку с главной. Заявки дублируются в журнал `leads/` (вне `public_html`, если права позволяют).
6. Яндекс Вебмастер: добавьте поддомен, укажите регион, отправьте `sitemap.xml`. Яндекс Бизнес: поставьте график «круглосуточно»
   (на карточке сейчас «ежедневно 9:00–22:00», по ТЗ должно быть 24/7 и на картах).

## Что проверено и чем

- Правила `.htaccess` (http → https, www → основной хост, `/index.html` → `/`, `/catalog/` → `/price/`, слэш на конце, 403 для
  служебных файлов, кэш и сжатие) проверены на Apache 2.4: 16 запросов, каждый редирект одним шагом на `https://`.
- `send.php` проверен на локальном SMTP (вход по AUTH LOGIN, два получателя, валидация, honeypot, лимит, проверка Origin,
  редирект без JS). Настоящий SMTP Бегета отсюда проверить нельзя: порт 465 недоступен из среды сборки.
- Вёрстка: Chromium на 320, 375, 430 и 1280 px, все 26 страниц: без горизонтального скролла, битых картинок и мелких
  тап-зон; на первом экране главной видны заголовок, цена «от», телефон, 24/7 и завод.

## Что нужно решить или подтвердить вам

- **Минимальный заказ.** Здесь 1 м³ (как вы подтвердили), на ekaterinburgbeton.ru написано «от 3 м³». Посетители увидят
  разные условия на двух сайтах одной сети.
- **Поддомен.** `verhnyaya-pyshma` выбран мной. Если нужен другой, поменяйте `domain`.
- **Доставка в цене или отдельно.** Неизвестно, сайт говорит нейтрально «стоимость зависит от расстояния и объёма».
- **Геостраница Екатеринбурга** без расстояния, времени и цены доставки: их нет ни в карточке, ни у вас. Заполните
  `distance_km`, `travel_time`, `delivery_cost` в `content/cities.json`, иначе страница слабее, чем требует ТЗ.
  Другие города добавляются туда же, когда будут реальные условия.
- **Бренд «Бетон Микс»** взят с основного сайта, а в карточке организация названа «Бетонно-растворный узел». Для единства
  данных (NAP) переименуйте карточку или скажите, какой бренд нужен на сайте.
- **Фото.** 22 снимка: 13 с карточки Яндекс Карт (часть загружена пользователями, права проверьте) и 9 из вашего архива.
  Видео из архива не использованы, их 20 файлов по 3–12 МБ.
- **Мессенджеры.** На ekaterinburgbeton.ru их нет, кнопок мессенджеров на сайте нет.
- **Позиции прайса с ошибками в карточке** (журнал в `content/_source/NOTES.md`): «Бетон по схеме Г» (9 строк с одинаковым
  названием) в сайт не попал; ошибочные классы и W исправлены при импорте и описаны в журнале.
- **Тексты политики и согласия** типовые по 152-ФЗ, их должен проверить юрист.

## Структура репозитория

```
content/        данные точки: site.json, prices.json, cities.json, rental.json, photos.json, photos/, _source/
src/            генератор: build.mjs, lib/ (данные, разметка, SEO), pages/ (шаблоны страниц), assets/ (CSS, JS, шрифты)
server/         send.php и пример конфига почты
tools/          import-yandex.mjs, check.mjs, shots.mjs, serve.mjs
tests/fixture/  вымышленные данные для проверки движка
docs/           BRIEF.md (описание полей), TZ-master-prompt.md (ТЗ)
dist/           готовый сайт для загрузки на хостинг
```
