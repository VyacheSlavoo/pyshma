# Сайт бетонного завода «Бетон Микс», Верхняя Пышма

Статический сайт (HTML без рантайм-фреймворков) для завода на ул. Обогатителей, 8. Цены, фото и отзывы взяты из карточки
на Яндекс Картах, структура разделов повторяет ulyanovka-beton.ru и ekaterinburgbeton.ru. Сайт собирается в папку `dist/`:
её содержимое целиком загружается на хостинг.

Адрес по умолчанию: `https://verhnyaya-pyshma.ekaterinburgbeton.ru` (поддомен основного сайта). Меняется одной строкой
`domain` в `content/site.json`, потом `npm run build`.

## Геостраницы городов

Города лежат в `content/cities.json`: название, падежи (`in`, `to`, `of`), координаты центра. Расстояние от завода считается
по прямой из координат (формула в `src/lib/data.mjs`), направление света считается так же; в тексте оно подписано «по прямой»,
потому что дорожное расстояние сайт не знает. Время в пути (`travel_time`) и цена доставки (`delivery_cost`,
`delivery_cost_unit`) не придуманы: пока их нет, страница пишет «называем при расчёте по адресу». Как только владелец впишет
реальные значения, они появятся в таблице условий, FAQ и разметке. Дорожное расстояние можно вписать в `distance_km`:
тогда подпись станет «по дороге».

Страницы похожи друг на друга на 64–65% (проверка в `tools/check.mjs`, порог красного замечания 75%): ориентиры отличаются
цифрами, примерами расчёта и логистическими ситуациями, а общее остаётся шаблонным. Чтобы страницы стали по-настоящему
разными, добавьте реальные локальные сведения в `notes` и `faq` каждого города (условия подъезда, типичные объекты, ограничения
по массе машин). Выдумывать их нельзя. Больше четырёх городов с отдельными страницами сайт не собирает без предупреждения.
Екатеринбург конкурирует по запросам с основным сайтом сети: решите, оставлять ли эту страницу.

## Что внутри

40 страниц: главная, прайс-лист, 10 разделов продукции и аренда АБН, 4 страницы марок (М200, М250, М300, М350), доставка,
4 геостраницы городов (Екатеринбург, Среднеуральск, Берёзовский, Арамиль), фото, о заводе, контакты, политика и согласие, «спасибо», 404, раздел статей (список
и 13 статей). Режим везде 24/7, НДС не упоминается, год основания и лаборатория не заявлены: в карточке этого нет.

**Цены.** Главная и `/price/` показывают карточки продукции с фото и ценой «от». Карточка ведёт на страницу продукции, где
работает конфигуратор: выбираются вид бетона, марка, подвижность (П), морозостойкость (F), водонепроницаемость (W), ПМД,
для арматуры сталь и диаметр, для аренды насос. Под выбор подбирается строка прайса, показываются обозначение, цена, итог
по объёму и пояснение к параметрам. Если выбранное значение не сочетается с остальными, подбирается ближайшая позиция, и
сайт пишет, что изменилось. Выбор попадает в адрес (`#pmd-m300-t15-p4-f150-w6`), ссылкой можно поделиться. Кнопка «Оставить
заявку» подставляет позицию и объём в форму. Те же позиции лежат в таблице под конфигуратором: она работает без JavaScript, и из
неё берутся значения для разметки Product/Offer. Цены в конфигураторе, таблицах и JSON-LD приходят из одних строк
`content/prices.json`, поэтому расходиться не могут (проверяет `npm run check`).

**Капча.** Во всех формах арифметический пример. Пример и подписанный токен выдаёт `send.php?captcha=1`, ответ проверяется на
сервере; токен действует один час и сгорает при первой попытке, так что перебор ответов не работает. Без JavaScript формы не
отправляются, вместо них выводится телефон.

**Статьи.** Файлы `content/articles/*.md`. Цены в тексте подставляются из прайса вместе с датой («Цены в статье на 1 октября
2026»), таблицы цен строятся из тех же данных. В поле `date` стоит дата публикации: статья с датой позже даты сборки на сайт не
попадает и появится при первой сборке после этой даты. Сейчас опубликованы все 13 статей (22 октября 2026): так попросил владелец. В один день статьи идут в порядке файлов.
Поле `related` задаёт три статьи для блока «Читать дальше»; разделы каталога ссылаются на статьи по списку `CAT_ARTICLES`
в `src/pages/catalog.mjs`. Правила файла и подстановки описаны в начале `src/lib/articles.mjs`, предпросмотр на любую дату:
`npm run build -- --date=2026-12-30`.

## Команды

```
npm install
npm run import        # обновить прайс, отзывы и список фото из карточки Яндекс Карт (нужен доступ к yandex.ru)
npm run build         # собрать dist/ (падает, пока обязательные поля в content/site.json пусты)
npm run check         # приёмка по ТЗ: проходы 1–4 (разметка, SEO, факты, композиция)
npm run check -- --layout   # + проход 5: Chromium на 320/375/430/1280 px и «холодный взгляд» на первый экран
npm run test:config   # конфигуратор в Chromium: каждое переключение даёт реальную позицию и верную цену
npm run test:form     # send.php на локальном PHP и заглушке SMTP: капча, повтор токена, лимиты, honeypot
npm run build:fixture # сборка на вымышленных данных tests/fixture (noindex), для проверки движка
npm run build:demo    # dist-demo/: копия для тестирования, открывается двойным щелчком по index.html (см. ниже)
npm run test:demo     # проверка демо-сборки в Chromium с file://
```

Цены обновляются раз в месяц: `npm run import && npm run build`, затем загрузить `dist/`. Дата «Актуально на …» берётся из
даты последнего импорта цен (1-е число того месяца), а не из даты сборки: пересборка ради новой статьи не выдаёт старые цены за
свежие. Если импорт старше 35 дней, сборка предупреждает. Эта же сборка выпускает статьи, чья дата уже наступила.

## Демо для тестирования

`npm run build:demo` собирает `dist-demo/`: те же страницы, но ссылки относительные, шрифты и иконки встроены, поэтому
сайт открывается двойным щелчком по `index.html` без сервера. Форма работает вхолостую: пример капчи считается в браузере,
заявка никуда не уходит. Сверху красная плашка «Демо». В прод эту папку выкладывать нельзя, в git она не попадает.

## Выкладка на Бегет

1. В панели Бегета добавьте сайт для поддомена `verhnyaya-pyshma.ekaterinburgbeton.ru`, в DNS домена поддомен
   направьте на хостинг (A-запись), включите бесплатный SSL (Let's Encrypt).
2. Загрузите **содержимое** `dist/` в корень сайта (`public_html`), включая скрытый `.htaccess`.
3. Почтовый ящик `zayavki@ekaterinburgbeton.ru` создан. Для отправки с домена в DNS должны быть SPF и DKIM Бегета, иначе
   письма уйдут в спам.
4. Создайте на сервере файл `send.config.php` на уровень выше `public_html` (образец: `send.config.example.php`). Нужны
   `smtp_host` `smtp.beget.com`, порт 465, `smtp_secure` `ssl`, `smtp_user` и `from` `zayavki@ekaterinburgbeton.ru`,
   `smtp_pass` с паролем ящика, `to` с адресом получателя, `site_host` с адресом сайта без https и `captcha_secret` с любой
   длинной случайной строкой. Файл с паролем в репозиторий не попадает (`.gitignore`), его нужно положить на сервер вручную.
   Заготовка с этими значениями лежит в `server/send.config.php` на машине, где велась работа, и пропадёт вместе с ней.
5. Отправьте тестовую заявку с главной. Заявки дублируются в журнал `leads/` (вне `public_html`, если права позволяют).
6. Яндекс Вебмастер: добавьте поддомен, укажите регион, отправьте `sitemap.xml`. Яндекс Бизнес: поставьте график «круглосуточно»
   (на карточке сейчас «ежедневно 9:00–22:00», по ТЗ должно быть 24/7 и на картах).

## Что проверено и чем

- Правила `.htaccess` (http → https, www → основной хост, `/index.html` → `/`, `/catalog/` → `/price/`, слэш на конце, 403 для
  служебных файлов, кэш и сжатие) проверены на Apache 2.4: 16 запросов, каждый редирект одним шагом на `https://`.
- `send.php` проверен на локальном PHP и заглушке SMTP (`npm run test:form`, 18 проверок): вход по AUTH LOGIN, два получателя,
  верный и неверный ответ капчи, повтор и подделка токена, просроченный токен, honeypot, чужой Origin, быстрая отправка, лимит
  заявок, ответ без JS. Настоящий SMTP Бегета отсюда проверить нельзя: DNS и порт 465 недоступны из среды сборки, первое письмо
  уйдёт только после выкладки.
- Конфигуратор (`npm run test:config`, 44 проверки): на всех 15 страницах продукции перебраны все варианты каждого параметра,
  цена и обозначение всегда совпадают с прайсом; клавиатура, объём и минимальный заказ, ссылка с якорем, передача позиции и
  капчи в форму, работа без JS, 375 px.
- Вёрстка: Chromium на 320, 375, 430 и 1280 px, все страницы: без горизонтального скролла, битых картинок и мелких тап-зон;
  на первом экране главной видны заголовок, цена «от», телефон, 24/7 и завод.

## Что нужно решить или подтвердить вам

- **Минимальный заказ.** Здесь 1 м³ (как вы подтвердили), на ekaterinburgbeton.ru написано «от 3 м³». Посетители увидят
  разные условия на двух сайтах одной сети.
- **Поддомен.** `verhnyaya-pyshma` выбран мной. Если нужен другой, поменяйте `domain`.
- **Доставка в цене или отдельно.** Неизвестно, сайт говорит нейтрально «стоимость зависит от расстояния и объёма»; итог в
  конфигураторе подписан «стоимость бетона» без слова «итого». Когда скажете, как устроено, поменяется одна настройка
  `delivery.price_includes_delivery` в `content/site.json`.
- **Геостраница Екатеринбурга** без расстояния, времени и цены доставки: их нет ни в карточке, ни у вас. Заполните
  `distance_km`, `travel_time`, `delivery_cost` в `content/cities.json`, иначе страница слабее, чем требует ТЗ.
  Другие города добавляются туда же, когда будут реальные условия.
- **Бренд «Бетон Микс»** взят с основного сайта, а в карточке организация названа «Бетонно-растворный узел». Для единства
  данных (NAP) переименуйте карточку или скажите, какой бренд нужен на сайте.
- **Оператор персональных данных.** В политике и согласии оператором назван бренд с адресом завода, юрлица в данных нет.
  Для 152-ФЗ нужно название организации или ИП: впишите его в `signature` в `content/site.json`.
- **Телефон и почта.** Телефон +7 (343) 298-10-71 взят из карточки, публичная почта betonniy.zavod@yandex.ru и получатель
  заявок info@ulyanovka-beton.ru взяты из ваших ответов и с сайтов сети. Подтвердите, что это те адреса.
- **Статьи.** Ссылки на ГОСТ и СП (7473-2010, 10181, 10180, 18105, 10060, 12730.5, 26633-2015, СП 70.13330) и порог зимних
  условий (ниже +5 °C среднесуточная и ниже 0 °C минимальная) пусть проверит технолог завода. Цифр о работе самого завода в
  статьях нет.
- **Основной сайт ekaterinburgbeton.ru** (правки вне этого репозитория). У него тот же телефон, почта и бренд, а режим в тексте и
  в JSON-LD «Пн–Пт 08:00–20:00, Сб–Вс 09:00–18:00», что противоречит 24/7 на этом сайте. Ссылки на поддомен там нет. Яндекс
  может счесть сайты одной организацией и показывать в выдаче один из них. Нужны: единый график 24/7, заметная ссылка на
  завод в Верхней Пышме, лучше отдельный телефон и ящик для поддомена.
- **Геостраница Екатеринбурга** закрыта от индекса, пока нет данных о доставке (см. выше). Как только в `content/cities.json`
  появится любое из полей `distance_km`, `travel_time`, `delivery_cost`, страница откроется в индекс и попадёт в sitemap.
- **Метрика и Вебмастер.** Номер счётчика (`metrika_id`) и код подтверждения прав (`yandex_verification`) в `content/site.json`
  не заданы; метатег подтверждения выводится, когда поле заполнено.
- **Строки прайса, которые стоит подтвердить.** При дублях импорт оставляет первую цену: бетон с ПМД М500 −5 °C П3 (в карточке
  7 100 и 5 150), фибробетон М250 П1 (4 520, 4 550, 4 600, 4 650). Бетон с ПМД М350 −5 °C (4 650) дешевле товарного М350 (4 700),
  а М500 и М550 оба отнесены к В40: проверьте у технолога. Керамзитобетон и сухой бетон в карточке заявлены «М100–М500»,
  «подвижность П2–П5», это тоже на проверку.
- **Статьи.** Темы зимнего бетонирования, расчёта объёма и выбора марки есть и в блоге основного сайта: тексты разные, но
  темы близкие. Цифры в статьях на проверку технологу: ЦПС 1:3 названа в прайсе М300 (обычно такая пропорция даёт марку
  ниже, зависит от цемента), марка по плотности D у керамзитобетона не указана, у старших марок бетон с ПМД −5 °C в прайсе
  дешевле бетона без добавки.
- **lastmod в sitemap.** Дата меняется, когда меняется содержимое страницы: хэши лежат в `content/lastmod.json`, этот файл
  нужно коммитить вместе с сайтом.
- **Шаблон аренды.** Нет данных о минимальной смене насоса, диаметре бетоновода, оплате простоя и зоне работы, поэтому на
  странице аренды этих сведений нет.
- **Фото.** 22 снимка: 13 с карточки Яндекс Карт (часть загружена пользователями, права проверьте) и 9 из вашего архива.
  Видео из архива не использованы, их 20 файлов по 3–12 МБ.
- **Мессенджеры.** На ekaterinburgbeton.ru их нет, кнопок мессенджеров на сайте нет.
- **Метрика.** Номер счётчика не задан (`metrika_id` в `content/site.json`); цель `lead` отправляется, когда он появится.
- **Позиции прайса с ошибками в карточке** (журнал в `content/_source/NOTES.md`): «Бетон по схеме Г» (9 строк с одинаковым
  названием) в сайт не попал; ошибочные классы и W исправлены при импорте и описаны в журнале.
- **Тексты политики и согласия** типовые по 152-ФЗ, их должен проверить юрист.

## Структура репозитория

```

src/            генератор: build.mjs, lib/ (данные, разметка, конфигуратор, статьи, SEO), pages/ (шаблоны страниц), assets/ (CSS, JS, шрифты)
server/         send.php и пример конфига почты
tools/          import-yandex.mjs, check.mjs, shots.mjs, serve.mjs, test-config.mjs, test-form.mjs
tests/fixture/  вымышленные данные для проверки движка
docs/           BRIEF.md (описание полей), TZ-master-prompt.md (ТЗ)
dist/           готовый сайт для загрузки на хостинг
```
